# 🚀 Leads Tracker - Chrome Extension

**Leads Tracker** is a productive browser extension that allows users to save, manage, and track important URLs directly from their browser tabs. It uses local storage to persist data, ensuring your links are saved even after you close the browser.

## ✨ Features
* **Save Current Tab:** Instantly save the URL of the active tab with one click.
* **Manual Input:** Type or paste any URL to save it to the list.
* **Persistent Storage:** Uses `localStorage` so your data is never lost.
* **Clean UI:** A simple and responsive interface built with CSS.
* **Delete All:** clear your list with a double-click (safety feature).

## 🛠️ Technologies Used
* **JavaScript (ES6+)** - Core logic and DOM manipulation.
* **HTML5 & CSS3** - Structure and styling.
* **Manifest V3** - Conforms to the latest Chrome Extension standards.
* **Vite** - Build tool for optimized development.

## 📥 How to Install & Use

Since this is a developer project, you can install it using **Developer Mode** in Chrome:

1. **Clone or Download** this repository to your computer.
2. Open Google Chrome and go to: `chrome://extensions/`
3. Toggle the **Developer mode** switch (top right corner).
4. Click on **Load unpacked** (top left).
5. Select the folder where you downloaded this project.
6. The extension is now installed! Pin it to your toolbar and start saving links.
